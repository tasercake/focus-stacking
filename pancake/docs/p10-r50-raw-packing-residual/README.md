# R50 RAW packing residual audit

The existing owned `RawSource` carries the bounded encoded bytes into Rawler. Canon CR3 compressed payload access is a borrowed subview of those bytes. The initial decoder and CR3 preflight both parse BMFF metadata from that source. The complete RAW boundary measured 17.808 s across 50 verified Canon frames at 4.49 mean busy cores in the one-copy registration diagnostic. That boundary covers source reading, decode, development, and normalization. [R50 stage diagnosis](../p10-r50-phase-287828a/README.md) · [Exact prior RAW parity](../p10-r50-raw-audit/host-aware-workers/README.md)

Pinned Rawler 0.8.0 clones the borrowed `RawImage` in `develop_intermediate`. The full Canon mosaic is 19,213,824 samples, or 38,427,648 bytes as `u16`. The scaled monochrome `as_f32().into_owned()` creates another 76,855,296-byte mosaic after rescaling. These copies lie inside the pinned developer and would need an owned-pipeline interface to remove while preserving the default processing steps. The compressed CRX decoder already parallelizes tile-plane work and integrates the planes in order. The external aggregate trace does not resolve the cost of these individual operations.

The application-owned normal-orientation RGB16 packing is a smaller independent candidate. A 5088×3392 frame contains 51,775,488 working f32 samples and 791 chunks of up to 65,536 samples. The original loop quantizes each chunk with pinned Rawler, normalizes those codes in the owned developed allocation and validates the result. Candidate `4f7b73d` visits those same disjoint chunks through the existing installed RAW pool on buffers of at least 16 chunks. Two or more workers must already be available in that exact pool. The pool remains capped at 15, so concurrent quantization can hold at most 1,966,080 bytes of temporary u16 values. The small, uninstalled, one-worker and transformed-orientation paths retain their original packing behavior. [Production source](../../src/image_io/raw.rs)

The native red control extracted the existing serial executor. On 1,273,809 working samples the test observed one active worker inside a two-lane test pool. The candidate observed both workers of the supplied installed pool, with exact quantized working bits. An independent caller-scope test passed the existing uninstalled pool and observed every callback on the caller. The test also decoded actual 704×640 Bayer DNG files using an asymmetric crop, nonzero black point, WB/color metadata and orientations 1 and 6. Across the 674×614 raster and its 614×674 rotated counterpart, 2,483,016 sample bits, geometry, source precision and embedded-profile behavior matched the serial path.
