- The first-reference Hybrid GPU path activates one shared optional `EstimationGPU`. CPU OpenCV feature matching and geometric validation remain part of the algorithm even with GPU assistance. A default similarity request can refine affine then Euclidean motion after an ORB fit, or take the Euclidean route when matching fails. The OpenCL refinement prepares the Gaussian cascade, computes workgroup partial Hessian and projection terms, and reads the terms back to the host. The host assembles a float32 3×3 or 6×6 Hessian and inverts it with NumPy. This is the singular-matrix source inside the observed catch path. The logs do not identify the failing frame, level, coefficients or resulting matrix rank.
